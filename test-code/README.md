## Summary:
- A responsive, single-page dog-sitting website developed based on Figma design provided. The website features a hero section, an "Our Services" section and three service cards. Built using HTML and CSS only, without JS or external frameworks. Responsiveness was tested at viewport widths of 375px, 726px, 1024px, and 1440px.

## Decisions:

- Mobile-first CSS with breakpoints at 726px and 1200px, plus 900px for hero padding.
- Cards stack with the image on top below 726px, sit as horizontal rows from 726px to 1199px, and form three columns from 1200px. The design only shows 1024px and 1440px, so 1200px is my choice.
- Hero photo is a CSS background under a dark gradient. The supplied wave SVG is added with ::after.
- Used Inter 500 for card headings from 726px and Quicksand on mobile.
- Linked the hero button to the services section because its destination was unspecified. Card links point to #.

## Differences from the design:
- Wave is scaled to 1800px wide instead of its native 1440px. As a stopgap so it still spans up to about 1800px screens, though it leaves gaps beyond that.
